# 🌿 Dr. Crop

**Dr. Crop** is a modern, AI-powered web application designed for intelligent crop disease diagnosis. It leverages advanced AI models to analyze crop images, helping farmers, agronomists, and agriculture enthusiasts identify plant health issues quickly and accurately.

Photograph a plant, get a structured disease report in seconds — and enjoy **5 free credits daily**.

---

## ✨ Features

- **🤖 AI-Powered Diagnosis:** Analyzes uploaded crop images using multiple AI providers (Google Gemini, OpenAI, Groq, Cohere) and returns a structured report covering the likely disease, symptoms, causes, treatment, and prevention.
- **🔐 Authentication & Accounts:** Secure email/password sign-up and login with JWT, plus **Google Sign-In**. Passwords are hashed with bcrypt. Users can manage their profile and upload an avatar.
- **💳 Credits & Payments (Stripe):** Every account receives **5 free diagnosis credits daily** (auto-reset). Additional credits can be purchased through Stripe Checkout, with idempotent credit granting via both the success-redirect verification and the webhook.
- **📓 AI Journal:** A daily agricultural-science journal auto-generated by Gemini — a rotating pool of 20 topics produces a fresh, factual research brief each day, publicly readable and paginated.
- **🗂️ Scan History:** Every diagnosis is securely archived with its image and report so you can track disease patterns over time.
- **📄 Legal & Support Pages:** Built-in **Terms & Conditions** and **Support** pages (with an interactive FAQ) for a production-ready experience.
- **☁️ Cloud Image Storage:** Secure image uploading and management via Cloudinary.
- **🎨 Modern & Responsive UI:** Built with React 19, Tailwind CSS v4, and GSAP for beautiful, smooth animations across all devices.
- **⚡ Robust Backend API:** Express.js RESTful API connected to MongoDB for auth, scans, journals, and payments.
- **🛡️ Secure & Optimized:** Implements best practices with Helmet, CORS, JWT-protected routes, and Morgan request logging.

## 🛠️ Technology Stack

### Client (Frontend)
- **Framework:** React 19 with Vite 8
- **Routing:** React Router v7
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP
- **Icons:** Lucide React
- **Language:** TypeScript
- **State:** React Context (Auth)

### Server (Backend)
- **Runtime:** Node.js
- **Framework:** Express.js 5
- **Database:** MongoDB with Mongoose
- **Authentication:** JSON Web Tokens (`jsonwebtoken`), `bcryptjs`, Google Sign-In (`google-auth-library`)
- **Payments:** Stripe (`stripe`)
- **Image Hosting:** Cloudinary
- **AI Integrations:** `@google/genai` (Gemini), `openai`, `groq-sdk`, `cohere-ai`
- **File Uploads:** Multer

## 🚀 Getting Started

Follow these instructions to set up the project locally for development and testing.

### Prerequisites

Ensure you have the following installed / available:
- **Node.js** (v18 or higher recommended)
- **MongoDB** (Local instance or MongoDB Atlas cluster)
- **Cloudinary Account** (for image storage)
- **Gemini API Key** and/or other AI provider keys (for AI diagnosis & journal)
- **Google Cloud OAuth Client ID** (for Google Sign-In — optional)
- **Stripe Account** (for credit purchases — optional for basic use)

### 1. Clone the Repository

```bash
git clone https://github.com/rumman2004/Dr.-Crop.git
cd "Dr. Crop"
```

### 2. Setup the Server

Navigate to the `Server` directory and install the dependencies:

```bash
cd Server
npm install
```

Create a `.env` file in the `Server` directory based on the provided `.env.example`:

```env
PORT=5000
CLIENT_URL=http://localhost:5173
MONGO_URI=your_mongodb_connection_string
MONGO_DB_NAME=dr_crop

# Cloudinary
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
CLOUDINARY_FOLDER=dr-crop/scans

# AI Providers
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-2.5-flash
OPENAI_API_KEY=your_openai_api_key
OPENAI_MODEL=gpt-4o-mini
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=llama-3.3-70b-versatile
COHERE_API_KEY=your_cohere_api_key
COHERE_MODEL=command-r-plus

# Auth
JWT_SECRET=your_long_random_secret
JWT_EXPIRES_IN=30d
GOOGLE_CLIENT_ID=your_google_oauth_client_id

# Stripe (credits / payments)
STRIPE_SECRET_KEY=your_stripe_secret_key
# Optional: needed only for the production webhook. The success-page
# verification grants credits without it, so local dev works either way.
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret
```

### 3. Setup the Client

Open a new terminal window, navigate to the `Client` directory, and install the dependencies:

```bash
cd Client
npm install
```

## 🏃‍♂️ Running Locally

To run the application locally, you will need to start both the frontend client and the backend server.

**Terminal 1 (Backend Server):**
```bash
cd Server
npm run dev
```
*The server will start running on `http://localhost:5000`.*

**Terminal 2 (Frontend Client):**
```bash
cd Client
npm run dev
```
*The client will start running on `http://localhost:5173`.*

Open your browser and navigate to `http://localhost:5173` to view the application.

## 📡 API Overview

All routes are prefixed with `/api`. Protected routes require an `Authorization: Bearer <token>` header.

### Auth — `/api/auth`
| Method | Endpoint | Auth | Description |
| ------ | -------- | ---- | ----------- |
| POST | `/signup` | — | Register with name, email, password |
| POST | `/login` | — | Log in and receive a JWT |
| POST | `/google` | — | Sign in with a Google ID token |
| GET | `/profile` | ✅ | Get the current user's profile |
| PUT | `/profile` | ✅ | Update profile details |
| POST | `/avatar` | ✅ | Upload a profile avatar |

### Scans — `/api/scans` *(all protected)*
| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| POST | `/analyze` | Upload an image and run AI diagnosis (consumes a credit) |
| GET | `/history` | List the user's past scans |
| GET | `/:id` | Get a single scan report |
| DELETE | `/:id` | Delete a scan |

### Journals — `/api/journals`
| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| GET | `/` | List journal entries (auto-generates today's entry if missing) |
| POST | `/generate` | Force-generate today's entry (debug) |

### Stripe — `/api/stripe`
| Method | Endpoint | Auth | Description |
| ------ | -------- | ---- | ----------- |
| POST | `/create-checkout-session` | ✅ | Start a Stripe Checkout session to buy credits |
| POST | `/verify-session` | ✅ | Verify the session on the success redirect and grant credits |
| POST | `/webhook` | — | Stripe webhook (raw body) for production credit granting |

### Health
| Method | Endpoint | Description |
| ------ | -------- | ----------- |
| GET | `/api/health` | Service health check |
